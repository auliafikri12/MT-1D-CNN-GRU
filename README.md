# MT-1D-CNN-GRU

This is one of my simple final project where I applied Convolutional Neural Network-Gated Recurrent Unit using Customized TensorFlow tools to solve one-dimensional inversion of Magnetotellurics. Magnetotellurics is one of Geophysical methods that is commonly used for geothermal explorations and volcano activities monitoring. Principally it uses natural electromagnetic sources to measure resistivity in subsurfaces. **This files is not ready to be used because I just create raw deep learning model in h5. form.** The result is good enough for a synthetic data, but I think we must fix a bit the model if you want to apply it for the real data.
